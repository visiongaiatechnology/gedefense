  predicate; SCTP/DCCP stay protocol-keyed; AF_PACKET/AF_TIPC/AF_VSOCK stay
  family-keyed.

  netlink fallback, capability honesty, registry resync, strict-plan exclusion.

  assertions (production code warning-free).

## 2. Systemd and deployment (FIND-001)

`packaging/systemd/gedefense-control.service`:

```
CapabilityBoundingSet=CAP_NET_RAW CAP_NET_ADMIN
AmbientCapabilities=CAP_NET_RAW CAP_NET_ADMIN
RestrictAddressFamilies=AF_UNIX AF_INET AF_INET6 AF_NETLINK AF_PACKET
```

`scripts/security-audit.sh` and `scripts/validate-systemd.sh` now enforce this
exact pair as an allowlist: any other capability, any other address family, or
any missing line fails. A transient `systemd-run` unit with
`NoNewPrivileges=yes` and this ambient pair successfully opened
`AF_PACKET/SOCK_RAW` as `nobody`, proving the grant is effective.
`SECURITY.md` and `docs/V6.1.0-VERIFICATION.md` §7 record the residual risk and
the planned dedicated capture helper.
