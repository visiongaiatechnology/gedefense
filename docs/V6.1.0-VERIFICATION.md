## 5. Residual technical risks

- A crash record identifies the Linux `comm` (15 bytes). nginx master and
  workers share `nginx`; masters are excluded via `/proc/<pid>/cmdline` for
  strict-scope classification, but a master crash cannot be distinguished from
  a worker crash by comm alone in the kernel record.
- The eBPF signal tracepoint reads `sig` at tracepoint offset 8 (after the
  8-byte common header); the control plane validates the signal value again, so
  an unexpected layout cannot create a false crash, but it could suppress
  events on a non-standard kernel.
- Module C's kernel prefilter matches addresses/ports; the payload predicate
  (`0x16`, QUIC long header) runs in bounded userspace after the filter.
- Module E phase 1 terminates TLS itself but forwards plain HTTP/1.1 to a
  loopback upstream; NGINX remains the production HTTP/2/QUIC path until V7.
- Enabling the edge listener converges at startup (`main.go` calls
  `syncEdgeProxy()` once after the module engines attach) and on the next
  settings/status read; a startup failure is logged and never blocks serving.

## 7. Audit remediation VGT-AUDIT-20261118-GD61 (FIND-001 … FIND-007)

Linux execution: WSL2 Ubuntu 24.04, systemd 255, Go 1.27.4 (GOTOOLCHAIN=auto),
Rust 1.97.1 + nightly-2026-07-16, Node 24.13.0, 2026-11-18.
Target tree: `.../Linux/6.1.0-github`.

### FIND-001 — control-plane capability boundary

`packaging/systemd/gedefense-control.service` now grants exactly
`CAP_NET_RAW CAP_NET_ADMIN` (`CapabilityBoundingSet` + `AmbientCapabilities`)
and allows `AF_PACKET` in addition to the previous families. Why:

- Module C AF_PACKET capture needs `CAP_NET_RAW` for `socket(AF_PACKET, ...)`.
- Module B CN_PROC netlink fallback needs `CAP_NET_ADMIN` to subscribe to the
  `NETLINK_CONNECTOR` `CN_IDX_PROC` group.

`NoNewPrivileges=true` and every other sandbox directive are unchanged. The
`SystemCallFilter=@system-service` setting was checked against `systemd-analyze
syscall-filter`: on systemd 255 it expands to `@network-io`, which contains
`socket`, `setsockopt`, `getsockopt`, `bind`, `sendto`, `sendmsg`, `recvfrom`,
`recvmsg`, `recvmmsg` and `sendmmsg`; `ioctl` is listed directly. No syscall was
added or removed, and the filter stays enabled.

Residual risk: the control plane now holds `CAP_NET_RAW` and `CAP_NET_ADMIN`.
A compromise of the Go control process can observe and inject local traffic
within the remaining sandbox limits (no `CAP_SYS_ADMIN`, no other address
families, seccomp filter intact); the blast radius is larger than the pre-6.1.0
"no capability" baseline. Planned hardening: a dedicated minimal privileged
capture helper, after which this grant is removed. The exact grant is codified
as an allowlist in `scripts/security-audit.sh` and `scripts/validate-systemd.sh`:
any other capability or address family fails both gates.

### FIND-002 — RDS socket family bypass

The kernel predicate moved into the host-testable
`cell_lsm_socket_create_denied` in `rust/gedefense-common/src/worker_guard.rs`:
`AF_RDS = 21` is denied on `family == AF_RDS` (the real
`socket(AF_RDS, SOCK_SEQPACKET, 0)` shape), SCTP/DCCP stay protocol-keyed and
AF_PACKET/AF_TIPC/AF_VSOCK stay family-keyed. The eBPF hook delegates to it and
no longer contains the dead `protocol == 21` test. Unit tests cover the positive
RDS socket and the negative `family=AF_INET, protocol=21` case.

### FIND-003 — dual-stack and custom-port blindness

- `control/internal/flowguard/bpf_linux.go`: classic-BPF generator keyed on
  `config.Ports` (≤ 8, deduplicated) for IPv4 and IPv6, TCP and UDP, with label
  resolution; the IPv4 IHL trick is preserved.
- `bpf_linux_test.go` contains a userspace cBPF interpreter: accepts
  443/8443/9443 on IPv4 and IPv6 (TCP+UDP), IPv4 header options, and rejects
  port 80, ICMP, ARP and IPv6 hop-by-hop headers.
- `snapshot_linux.go` dumps `AF_INET` and `AF_INET6` via `INET_DIAG` and merges
  the results; dual-stack `[::]:443` sockets are visible and `NLMSG_ERROR` is
  surfaced instead of a silent empty result.
- `capture_linux.go` decodes IPv6 TCP/UDP (plain 40-byte header; extension
  headers are a documented bounded limitation), uses `config.Ports` for UDP, and
  keeps the 0x16 / QUIC-long-header predicate in userspace.

### FIND-005 — worker-guard honesty and master-cgroup safety

- The eBPF source reports `ebpf` only after `attached=1`; `attached=false` or a
  mid-run detach disarms the map (`WORKER_GUARD_SET 0`), reports `none` with the
  reason and returns `ErrWorkerGuardInactive`; the engine then falls back to the
  netlink source. Netlink reports `netlink` only after the kernel accepted the
  CN_PROC subscription.
- `workerGuardStatus` derives `capability:"active"` from a live source only
  (eBPF additionally requires attached=true); otherwise it is `inactive` with a
  concrete reason. Existing wire keys are unchanged; `skipped_cgroups` and
  `strict_reason` are additive.
- Registry changes (`comms`/`uids`) are detected per reconcile tick; removed
  entries are deleted through `WORKER_GUARD_COMM_DEL` / `WORKER_GUARD_UID_DEL`
  and the source is restarted, so stale registrations cannot stay armed.
- `ScanProcesses` is now a two-pass scan: pass 1 records cgroups that host an
  excluded master/control process (the systemd `nginx.service` cgroup is shared
  by `nginx: master process` and its workers), pass 2 skips those cgroups,
  surfaces each skip with cgroup id/path/comm/reason and never sets
  `Worker.Strict`, so the Titan strict plan cannot include the master.

## 8. R2 -> R3 Remediation (FIND-008, FIND-009)

- **FIND-008 (capture-helper privilege split):** `gedefense-control.service`
  is restored to zero Linux capabilities (`CapabilityBoundingSet=`, no
  `AmbientCapabilities`, no `AF_PACKET`). Passive `AF_PACKET` capture and
  `CN_PROC` Netlink fallback now execute inside the isolated
  `gedefense-capture-helper.service` unit (`gedefense-control --capture-helper`,
  `RuntimeDirectory=vgt-gedefense-capture` `0700`, `IPAddressDeny=any`,
  `RestrictAddressFamilies=AF_UNIX AF_NETLINK AF_PACKET`, zero access to
  `/etc/vgt/gedefense`, `/var/lib/vgt/gedefense`, or `/run/vgt-gedefense`).
  The control plane connects to `/run/vgt-gedefense-capture/capture.sock`
  (`0600`, `SO_PEERCRED` verified, symlink-refused, read-only bounded stream).
- **FIND-009 (Web Exposure advisories UI crash):** `control/web/v61/exposure.js`
  now renders `payload.catalogue` through `renderRows('exposureAdvisoryRows', ...)`
  instead of calling undefined `renderAdvisoryRows(...)`.
- **Bonus hardening:** `edgeproxy` also strips inbound `X-Real-IP` before
  `SetXForwarded()`; `workers.js` renders `status.strict_reason` alongside
  `status.reason`; `packaging/arch/PKGBUILD` is bumped to `6.1.0` and packages
